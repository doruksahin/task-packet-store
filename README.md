# task-packet-store

Read and write AdCreative task packets from a local file system or from Google Drive. One CLI for
every SDLC tool that consumes or produces packet content, on a laptop or in CI.

Status: design phase. The code arrives with plan step 03.

- Start with [docs/design/README.md](docs/design/README.md). It has the 30-second overview and the map.
- Track progress in [docs/plan/README.md](docs/plan/README.md). It is the checkpoint board.
